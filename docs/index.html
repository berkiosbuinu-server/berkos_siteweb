Note sur les assistants IA

La documentation publique facilite la découverte et l'utilisation du langage, mais ne signifie pas qu'un modèle a été entraîné sur BERKIOS ni qu'il possède une intégration native. Les assistants doivent s'appuyer sur cette documentation et valider le code avec le compilateur.
