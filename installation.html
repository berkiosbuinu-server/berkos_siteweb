Guide d’installation

Installez BERKIOS GRAPHIC, puis préparez les outils nécessaires selon ce que vous souhaitez faire : utiliser le Studio, créer des applications Flutter ou compiler pour Windows, Android et le Web.

À retenir

Pour simplement installer et ouvrir BERKIOS GRAPHIC, commencez par télécharger l’installateur Windows depuis GitHub. Flutter, Node.js et Android Studio sont surtout nécessaires lorsque vous utilisez les fonctions de développement ou de génération d’applications. Les besoins exacts dépendent de la cible choisie.

01 / AVANT DE COMMENCER

Prérequis

A

Système d’exploitation

Un ordinateur Windows 10 ou Windows 11 64 bits est recommandé pour l’installateur Windows publié sur la page de téléchargement.

B

Connexion Internet

Recommandée pour télécharger l’installateur, récupérer les dépendances de projet et installer les outils de développement.

C

Droits d’installation

Selon la configuration de Windows, vous devrez peut-être autoriser l’installation ou saisir les identifiants d’un compte administrateur.

02 / INSTALLER BERKIOS GRAPHIC

Installation du Studio

  1. 1

    Télécharger la version publiée

    Ouvrez le centre de téléchargement. Les fichiers MSI et EXE sont récupérés depuis les ressources de la dernière release GitHub publiée.

    Accéder aux téléchargements ↗
  2. 2

    Lancer l’installateur

    Ouvrez le fichier .exe ou .msi téléchargé, puis suivez les étapes affichées. Si Windows affiche une demande de confirmation, vérifiez que le fichier provient bien de la release officielle avant de continuer.

  3. 3

    Ouvrir le Studio

    À la fin de l’installation, lancez BERKIOS GRAPHIC depuis le menu Démarrer ou le raccourci créé par l’installateur.

  4. 4

    Vérifier les fonctions de génération

    Si vous voulez compiler une application, installez les outils correspondant à votre cible dans la section suivante. Redémarrez le Studio après toute modification des variables d’environnement.

03 / OUTILS DE DÉVELOPPEMENT

Dépendances à installer

Installez uniquement les outils nécessaires à votre usage. Les liens ci-dessous pointent vers les sites officiels des éditeurs.

Applications Flutter

Flutter SDK

F

Nécessaire pour générer et compiler des applications Flutter. Téléchargez le SDK, extrayez-le dans un dossier de votre choix et ajoutez son dossier bin au PATH de votre environnement. Berkios Graphic ne doit pas supposer un emplacement fixe.

Vérification dans un terminal : flutter --version, puis flutter doctor -v.

Important pour le PATH

Ne copiez pas un chemin d’exemple trouvé dans ce guide comme s’il était universel. Le dossier d’installation dépend de chaque ordinateur. Ajoutez le chemin réel de l’outil à la variable d’environnement PATH, puis fermez et relancez le Studio pour qu’il récupère les nouvelles variables.

04 / DIAGNOSTIC

Vérifier l’environnement

Ouvrez PowerShell ou l’invite de commandes Windows et exécutez les commandes correspondant aux outils installés :

where.exe flutter
flutter --version
flutter doctor -v
where.exe node
node --version
npm --version

Si une commande n’est pas reconnue, vérifiez le PATH et redémarrez le terminal. Si PowerShell ne lance pas un outil Windows, essayez également l’invite de commandes (CMD). Le bridge doit rechercher l’outil dans l’environnement de l’utilisateur et ne doit pas coder en dur le chemin d’installation.

Une compilation échoue ?

Consultez d’abord la première erreur réelle dans le journal. Une erreur Dart dans le code généré doit être corrigée dans le générateur de Berkios Graphic ; une erreur de détection doit être diagnostiquée séparément de l’échec de compilation.
